# 第三方 SOP 第一组发送优先级

- 目标：第三方 SOP 第一消息组调用聚合平台主动发送接口时携带高优先级标识，并提供对接合同。
- 非目标：不调整 SOP 过滤、消费、送达回调或聚合平台队列实现。
- base SHA：`7ae57eb075be31838ca7ae1bb2e7b1cdc2c206d8`
- 生产基线：本任务不部署，未现场核验生产 release。

- 判断合同：用户已确认所选消息组 sortOrder 是客户全部 SOP 的顺序；仅值为 1 时标记高优先级，缺失或非法值按普通优先级。
