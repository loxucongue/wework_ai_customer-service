## 本轮修复

- 泛地标/短路名无父级城市时不再误用门店库城市别名，例如“中山路”不能被当成“中山市”。
- 结构化地址或门店地址命中时，允许门店库中的精确地址事实覆盖地图行政区口径差异；但短省份/短城市不会因此被当成精确地址。
- 短区县回复先按门店库唯一性判断：唯一省市区签名可直接匹配，多城市同名区县必须追问城市。
- 显式城市 + 区县可见区域命中时，地图 geocode 把行政区解析偏移不再提前阻断门店事实。
- 详细地址包含城市但附近没有本地门店时，不再串到同名区县的其他城市门店。
