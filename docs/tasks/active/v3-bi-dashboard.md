# v3-bi-dashboard

## 目标

- 基于既有 V3 策略埋点管理接口，交付首版产品化 BI 面板。
- 优化管理端信息架构、筛选、指标概览、维度排行、转化与问题监控。
- 核实“预约卡点话术”和“SOP异议素材”页面是否仍被运行链路使用；退役独立页面和导航，同时保留仍有运行依赖的接口与底层服务。

## 非目标

- 不修改 V3 Reply 销售语义。
- 不新增第二套统计事实或前端自行计算业务口径。
- 不启用延时逼单发送，不写生产数据。
