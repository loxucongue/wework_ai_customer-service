## A/B/C 对照结论

- 固定条件：baseline `93a99f5c50608e1513bd09272dcc3ac7600a20d5`、DeepSeek `deepseek-chat`、temperature `0.15`、每例 3 次、同一事实输入、交错候选顺序。AI 评审只作为开发筛选，不能代替业务盲评。
- A 输入整理：在 10 例筛选中，baseline 胜 10、A 胜 4、持平 15；论据、自然、多轮连贯和下一步均有回退，因此舍弃。评测用上下文整理器保留在离线工具中，不接入正式 Reply。
- B Prompt 精简：50 例、3 次共 150 组对照中，baseline 胜 35、B 胜 42、持平 73。B 的当前请求、论据、自然和下一步均值小幅提高，但多轮连贯从 `1.560` 降到 `1.533`，P95 从 `3533ms` 升到 `3564ms`；优势不稳定且远未达到隐藏盲评胜率门槛，因此舍弃。
- B 的小幅补丁只在 12 个失败配对例中复测，baseline 胜 16、候选胜 7、持平 13；多轮连贯和下一步明显下降，继续舍弃。
- C 输出减负：消费者追踪确认 `primary_objective`、顾虑/姿态等字段参与跨轮记忆或观测，缺少唯一、安全的代码派生关系；未实施运行时改动。
- 历史实验提交已通过后续 revert 和最终树恢复撤销。最终候选不包含 Prompt、上下文顺序或输出结构的产品行为变化。
