# 产品背景与统一目标

- status: current-product-context
- owner: product / engineering
- source_of_truth: 产品确认、项目宪法与当前 V3 合同

## 业务背景

AI Paths 面向企业微信淡斑活动销售接待。客户消息通常很短、上下文细碎，同一句话可能同时包含咨询、顾虑、情绪和成交信号。系统不能只做问答，也不能不顾客户状态机械逼单；目标是在事实可靠、安全合规的前提下，像真人销售一样完成“答疑、解卡、继续主线、引导预约金”的连续过程。

所有 `slXXXX` 标识当前都表示同一业务知识租户下的不同接待企微号。它们可以共享跟进序列、卡点话术、B 单规则和策略目录，但不能共享客户记忆、订单、发送次数、SOP 进度或主动触达状态。

## 产品目标

1. 正常客户：自然介绍效果、活动、门店与预约流程，并在客户具备行动条件时引导预约登记和预约金。
2. 有卡点客户：先回答当前问题，使用已发布跟进序列和卡点话术作为参考，化解顾虑后再回到主线。
3. 有成交信号客户：由业务 B 单规则提供“什么时候可以开始”的候选，由 B 单策略提供节奏和节点，由对应话术类型提供表达参考，最终仍由 V3 Reply 决定本轮是否进入、推进、暂停或结束。
4. 有情绪客户：情绪用于调整篇幅和压力。爆粗、讲价、短句或抱怨第三方不等于高置信愤怒；客户表达层面只有明确退订构成永久退订，人工接管、关系删除、医疗高风险和具体严重客诉/退款纠纷另由独立事实或风险状态停止 AI 营销。
5. 门店客户：必须先取得权威门店事实。已确认门店后，停车和已发布营业时间属于公开详情；楼层、房间、接待方式和详细到店指引只有在权威已付且唯一门店确定后才能提供。客户尚未预约且没有新卡点时，应答清当前可回答事实并按已交付主线自然推进，不得重复已发送的门店地址或门店卡。
6. 沉默客户：只对真实开过口、最新状态明确为 AI 接待且通过退订、订单、最新消息等安全检查的客户生成和执行唤醒计划。
7. 产品与运营：能够从日志和 BI 看清本轮意图、情绪、卡点、候选序列/话术、最终采用、发送、后续开口和订单变化。

## 统一运行原则

```text
客户消息与可靠历史
  → 权威客户/订单/门店事实
  → Semantic Router 识别检索和工具需求
  → 跟进、话术与 B 单目录候选
  → V3 Reply 唯一完成销售语义判断和客户回复
  → 代码校验事实、安全、交易与幂等
  → 最小核心结果同步持久化 → HTTP 返回
                              ↘ 可靠收尾 Worker：轨迹、BI、Shadow、outbox 与后续归因
```

- 模型负责业务语义、客户心理和销售节奏；代码负责事实、工具、schema、权限、幂等和强安全边界。
- Router、规则、序列、话术和门店工具都是 Reply 的参考证据，不是第二个销售决策者。
- 一轮最多采用一个解题方向和一个销售推进动作。新卡点未解决时必须先解卡。
- 软拒绝允许降压后换价值角度继续；明确“别联系、别发了”等退订必须立即停止商业营销。
- B 单决策不能授权付款、预约成功、门店、名额或效果事实；交易动作必须满足独立权威事实合同。

## 术语

| 术语 | 含义 |
| --- | --- |
| 卡点 | 当前阻碍客户理解、信任或行动的具体顾虑。 |
| 跟进序列 | 解决某类卡点的节奏与步骤参考，不是必须机械执行的脚本。 |
| 卡点话术 | 同一卡点类型下供 Reply 取材和改写的已发布表达。 |
| B 单规则 | 业务总结的可进入成交推进的场景条件，回答“现在是否具备资格”。 |
| B 单策略 | 在符合条件时可选择的推进节奏，回答“用哪套方式推进”。 |
| B 单话术 | 策略节点指定类型下的表达候选，仍需结合本轮事实与客户状态改写。 |
| Shadow | 只记录建议或计划，不产生真实客户触达。 |
| 权威事实 | 来自当前订单、门店、支付、活动等受控数据源的可验证事实。 |
| 销售接触边界 | `corp_id + wechat + external_userid`，用于隔离客户状态；平台客户 ID 是独立的第三方记录标识。 |

## 明确非目标

- 不用关键词规则替代正常销售语义判断。
- 不把知识库话术当成价格、退款、门店、名额、付款或预约事实。
- 不把 AI 初评、结构覆盖率或时间窗口相关性宣传为正式业务准确率或成交因果。
- 同步 V3 Reply 派生的延时 B 单节点和四大区跟进当前只允许 Shadow，不因目录存在而自动发送。开口后沉默唤醒是独立 Worker 链，只有通过计划前与逐次发送门禁后才可真实触达，不能与 Shadow 混为一谈。
