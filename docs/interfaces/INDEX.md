# 接口文档索引

本目录记录 AI Paths 与外部系统之间的接口边界。只记录稳定合同、鉴权位置、读写性质和运行风险；不保存 token、客户原文、请求日志、模型输出或一次性测试报告。

- code_verified: 2026-09-10 Asia/Shanghai, `main@0e7f76e5`

## 文档

- [外部依赖接口](external.md)：AI Paths 调用第三方、平台、模型和知识服务的接口。
- [对外暴露接口](public.md)：第三方、前端或运营工具调用 AI Paths 的接口。

具体请求/响应 schema 以当前代码和链接的专项合同为准；本目录不复制平台动态目录、生产地址、白名单或凭证。

## 维护规则

- 新增或修改接口时，同步更新本目录中对应文档。
- 动态状态、线上地址、release、数据库和服务健康状态不写入本目录；发布前必须现场核验。
- 涉及发送、支付、订单、客户资料写入或策略终态回传的接口，必须明确标注是否会产生外部副作用。
- 保留但禁用的兼容端点必须明确写出禁用状态，不能与当前可用能力混列。
- V3 客户回复仍是唯一产品回复入口；历史 V1/V2 路由不得因兼容说明重新启用。
