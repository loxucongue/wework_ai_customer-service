# AI 销售策略运行合同

- status: candidate
- owner: reply-runtime
- source_of_truth: `ai_paths/app/policies/ai_sales_policy_v1.json`、`sales_strategy_catalog_v1.json` 与当前 V3 代码

## 边界

- V3 Reply 是唯一销售语义决策点；不另建意图、卡点或逼单决策链。
- 策略配置描述场景、节点目标、节奏和素材来源；模型决定是否采用，代码只校验稳定 key、权威事实、交易边界和发送结果。
- 话术只作改写参考。每次回复最多采用一个解题方向和一个合法销售动作。
- 图片和视频只能来自本轮检索后保留的候选 URL；不得编造素材、门店、订单、活动或支付事实。

## 当前开关

- 策略目录默认关闭；显式启用后也只提供候选，不替代当前 V3 回复。
- 延时逼单和四大区跟进维持 `shadow`：允许审计，不允许真实发送。
- 意向分只用于分析，不触发回复、逼单、开单或发卡。

## 交易与触达边界

- `closing_decision` 不授权开单、发卡或确认预约。
- 预约金卡要求同门店、同金额的真实有效未付订单。
- 人工接管、明确退订、已付、会话读取失败、客户已回复和重复发送阻止延时任务。
- 延时任务按 `corp_id + wechat + external_userid/customer_id` 隔离；客户回复即取消旧节点并重新进入 V3。

## 启用前验证

先人工确认策略内容和素材事实；再由单独任务完成隔离模型验证与全链路 shadow。验证失败不得通过关闭事实过滤、订单校验、退订、人工接管、会话读取或 WeChat 隔离来绕过。
