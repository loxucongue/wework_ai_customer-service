# V3 Reply 质量与全链路评测规范

- status: active-standard
- owner: product / quality / reply-runtime
- source_of_truth: 项目宪法、V3 合同与生产事故复盘

## 目的

统一“单节点测试、隔离全链、全场景和上线验证”的含义。测试报告必须准确说明覆盖层级，不得把部分链路的高通过率扩大解释为完整生产质量。

## 四级验证

| 级别 | 名称 | 必须覆盖 | 可以证明 | 不能证明 |
| --- | --- | --- | --- | --- |
| L1 | 确定性节点验证 | schema、枚举、检索、事实、安全和幂等函数 | 代码合同没有明显回归 | 模型表达和真实服务生命周期 |
| L2 | 模型图隔离评测 | Router、候选、工具事实、Reply、校验；不发送、不写生产 | 冻结输入下的语义、召回和回复表现 | 已发送结构消息去重、生产持久化尾部、完整 HTTP 延迟 |
| L3 | 模拟生产生命周期 | 真实数据形状、内存/临时库、结构化历史、持久化和响应组装；外部副作用阻断 | 端到端状态连接、去重和完整进程内耗时 | 线上网络、真实数据库负载和服务配置 |
| L4 | 部署后全链验证 | 同一 clean main SHA、实际服务角色、数据库、Nginx、日志、回执和 worker | 当前发布在生产拓扑下可运行 | 长期业务准确率和成交因果 |

只有 L1–L4 按风险全部通过，且业务状态矩阵达到约定覆盖，报告才能使用“全链路通过”。“全场景”还必须给出场景维度与状态组合清单，不能只按客户消息关键词或大类抽样。

## 场景必须同时包含状态

每个样本至少明确：

- 当前客户消息及连续消息顺序。
- 最近真实客户可见、且已送达的文本和结构化消息。
- 客户是否已预约、已付、交易终态或人工接管。
- 门店是否未查询、已匹配、已发卡、客户改店或明确要求重发导航。
- 当前卡点、上一活动卡点及是否已经解决。
- 当前意图、情绪、退订/投诉/健康风险。
- 本轮允许的唯一推进目标，以及禁止动作。

例如“门店场景”至少拆为：首次找店、位置不足追问、已确认未发卡、已发卡再问地址、已发卡问停车、未预约问停车、已预约问停车、客户改城市、超过 6 家门店列表和无本地门店。

## 不发送、不保存时的正确隔离

- 生产发送、支付、建单、预约、策略回写、dispatch、outbox 和 Shadow 客户触达客户端全部替换为调用即失败的阻断器。
- Repository 使用内存数据库、临时数据库或事务回滚；必须模拟真实 schema、历史事件数量和结构化 `store_address` 等已送达记录。
- `eval_request_id` 在生产 run、usage、dispatch 和 outbox 中反查必须为零。
- 不写生产不等于跳过持久化逻辑；L3 仍要执行等价的保存、批量历史写入和响应组装，只把目标换成临时存储。

## 评审与硬失败

- AI 评审只提供初评，不能单独决定正式通过。
- 下列问题由确定性断言直接判失败：重复已送达结构消息；明确退订仍推进；无权威事实承诺门店/付款/预约/效果；健康风险强推；应连接预约目标却只问无目的时间；发生任何生产写入或发送尝试。
- “直接价值交付”必须单独验收：活动价等已知事实不能先问客户要不要发；Reply 选择效果案例处理卡点且存在未重复的真实媒体时，应在同轮用文字引出并交付素材。只说“要不要看效果/需要的话再发”、采用带媒体话术却未选择素材，以及已发图片重复发送都判失败；退订、投诉、高风险和素材无关场景不得为提高交付率强发。
- 评审输入必须包含客户实际可见的全部消息类型，不能只拼接 `type=text` 后忽略门店卡、付款卡、素材或其他结构消息。
- 指标必须分别报告：检索召回、条件采用、策略结构覆盖、业务分类准确率、最终回复通过率和安全失败；不能混用分母。

## 性能口径

至少同时记录：

- Router、外部知识、门店/订单工具、Reply 和修复的分段耗时。
- 模型决策图总耗时。
- 请求接收至 HTTP 响应完成的端到端耗时。
- 图执行结束后的持久化、BI、outbox、历史事件和响应组装尾部耗时。
- P50、P95、P99、超时、重试和兜底率。

如果只测到 `graph.ainvoke()`，必须标记为“模型图耗时”，不得称为接口端到端耗时。

## 数据和报告

- 客户原文、真实身份、原始模型输入输出和详细报告只保存在 ignored `artifacts/`，默认 7 天 TTL。
- Git/docs 只记录测试范围、分层、聚合结果、失败分类和结论，不保存客户数据。
- 任何准确率在业务逐条确认前必须标注“AI 初评”。
